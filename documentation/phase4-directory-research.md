# Phase 4 — Directory / Backlink Research

Researched 2026-09-22. Per the plan, deliberately excludes gig marketplaces (Upwork, Fiverr,
Freelancer, Cad Crowd) — those stay as a secondary channel already in use, not part of this list,
since leading with them would undo Phase 0's wedge-positioning work.

## Findings

**GoodFirms** (goodfirms.co) — a B2B service-provider review/directory platform with an existing
"3D Modeling and CAD" category (`goodfirms.co/engineering/3d-modeling-cad`) already listing
real BIM/CAD outsourcing companies. Legitimate, widely used by businesses researching B2B service
vendors — categorically different from a gig marketplace (buyers browse vetted company profiles
and reviews, not post jobs for bids). **Recommended** — worth a company profile listing.

**Clutch.co** — a well-known B2B agency/service-provider directory (software dev, IT services,
design, and other professional services, including engineering firms). Same category as
GoodFirms: review-driven, not bid-driven. **Recommended** as a second option, though Clutch
leans more toward larger/established firms in some categories — worth checking their submission
requirements before committing time to a listing.

**AEC Listing** (aeclisting.net), surfaced in an initial general web search — **checked and
rejected**: the domain does not resolve (`ENOTFOUND`), so this is either dead or was a bad search
result. Do not pursue.

**AIA's Resource Center / member directory** — checked and **not applicable**: AIA membership
and its directory are gated to licensed US architects/firms, which doesn't fit this business
(Lahore-based, delivering BIM/CAD production rather than US-licensed architecture-of-record
services).

## Recommendation

Start with a **GoodFirms company profile** — it's free to create a basic listing, directly
matches the "3D Modeling and CAD" / BIM outsourcing category with real comparable companies
already listed, and is a legitimate directory rather than a marketplace. Revisit Clutch once the
GoodFirms listing is live and has a review or two, since Clutch's stronger vetting will be an
easier sell with existing third-party proof.
