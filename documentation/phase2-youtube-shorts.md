# Phase 2 — YouTube Shorts (Draft Scripts)

Per the plan, these are built entirely from existing portfolio assets — no new renders or
production needed, just a screen-recording/editing pass (e.g. CapCut or Premiere) over stills
already on the site, with voiceover or on-screen captions. Vertical 9:16, 30–60 seconds each.

Existing assets to pull from (already live on the site, no new asset creation needed):
- Interior renders: `public/portfolio/visualization-showcase/01-home-office.jpg` through
  `05-classical-dining.jpg`
- Exterior renders: `public/portfolio/barn-residence-vray.jpg`,
  `public/portfolio/bimcad-workflow/11-facade-closeup-render.webp`,
  `public/portfolio/bimcad-workflow/12-cube-facade-render.webp`
- BIM/CAD production screenshots: `public/portfolio/bimcad-workflow/01` through `09` (window
  schedules, Grasshopper scripting, GIS terrain, structural calc, facade paneling script, solar
  analysis, diagrid pattern)

Cadence: one short every 1–2 weeks, same rhythm as the (currently paused) LinkedIn posts — don't
run both at once, alternate so there's always something going out without burning through all the
material in a month.

## Short 1 — "What LOD 350 Actually Looks Like" (ties directly to the LOD guide)

**Hook (0–3s):** On-screen text: *"What does 'LOD 350' actually mean?"* over a zoomed-in BIM
schedule screenshot (`01-window-schedule.jpg`).

**Body (3–40s):** Cut between 3–4 BIM/CAD workflow screenshots (window schedule → structural
model calc `05` → facade paneling script `06`), each held ~5–8s, with short caption text per
frame:
- "LOD 100: just the massing."
- "LOD 300: exact size, shape, and position."
- "LOD 350: + how it connects to everything around it."
- End on a finished exterior render (`barn-residence-vray.jpg`) with: *"This is what LOD 350 looks
  like on delivery."*

**CTA (last 3s):** *"Full breakdown — link in bio"* → `/guides/lod-guide/`.

**Voiceover option (if recording audio):** Short, matter-of-fact, no hype — this is a
practitioner explaining a real technical distinction, not a marketing pitch.

## Short 2 — Interior Render Reveal (before/after style, structure → finish)

**Hook (0–3s):** Start on a plain BIM/CAD screenshot (e.g. `02-grasshopper-rolling-polygon.jpg`
or a structural/coordination view) with text: *"From model to render."*

**Body (3–30s):** Hard cut to the finished interior render it corresponds to conceptually (best
pairing: a structural/massing screenshot → `03-bright-loft.jpg` or `02-dark-living-room.jpg`).
No need for a literal same-project before/after — a coordinated model view into a finished
interior communicates the same idea. 2–3 more interior renders as a quick reveal montage
(`01-home-office.jpg`, `04-restaurant-interior.jpg`, `05-classical-dining.jpg`), fast cuts (~2s
each) with subtle zoom.

**CTA (last 3s):** *"More renders — full gallery on the site."* → homepage gallery section.

## Short 3 — Facade / Exterior Study (parametric process → finished facade)

**Hook (0–3s):** Text over `06-facade-paneling-script.jpg`: *"This isn't drawn by hand."*

**Body (3–35s):** Show the parametric/scripting process — `09-diagrid-pattern-script.jpg`, then
`06-facade-paneling-script.jpg` — with a one-line caption on each explaining what's being solved
(panel count, structural rhythm, solar exposure). Cut to the finished facade renders:
`11-facade-closeup-render.webp` and `12-cube-facade-render.webp`, held longer (~5s each) since
these are the payoff shots.

**CTA (last 3s):** *"Computational design, delivered globally — link in bio."* → homepage.

## Production notes

- No talking-head footage needed — all 3 scripts work as pure screen/still-image edits with
  captions, which keeps production to an editing pass rather than filming.
- Keep total video count to what's realistic — 3 shorts is enough for a first batch; more can be
  drafted once these are published and it's clear which format performs.
- These are drafts only — nothing has been recorded, edited, or uploaded. Actual video editing
  and the YouTube upload itself are outside what can be done in this environment; this doc gives
  the shot list and script so that step is fast whenever picked up.
