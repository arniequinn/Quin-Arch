# Phase 2 — LinkedIn Cadence (Draft Posts)

Four posts, one per case study, ready to copy-paste and publish on Arslan's LinkedIn. Cadence:
**one every 1–2 weeks**, not all at once — this is meant to look like an ongoing practice, not a
content dump. Order below is suggested (strongest/most visually striking hook first), but any
order works.

Voice notes (per the [wedge positioning decision](../.claude — see memory `business-positioning-decision`)):
- No cost/savings framing, no "%," no "affordable."
- Lead with the specific technical problem, not "check out my portfolio."
- Each post ends with a soft link to the case study page, not a hard sales pitch.
- 2–3 hashtags max — enough for discovery, not marketplace-spam.

## Post 1 — Texas Coastal Beach House (hurricane wind zone permit set)

> Most permit rejections on coastal residential projects don't come from the architecture — they
> come from the structural narrative not matching the wind zone.
>
> On this elevated beach house on the Texas Gulf Coast, the brief was straightforward: a
> cathedral-ceiling living space, a wraparound cantilevered sundeck, and full IRC coastal
> high-wind compliance on a deep timber-piling foundation.
>
> The part that actually takes experience isn't drawing the piles — it's knowing which uplift and
> shear load paths the plan examiner is going to check first, and documenting them so the first
> submission is the only submission. That's the difference between a 2-week permit cycle and a
> 6-week one.
>

## Post 2 — Slamburger Commercial Kitchen (MEP + health code coordination)

> A commercial kitchen fit-out lives or dies on coordination most people never see: hood chase
> routing, grease trap placement, and ADA restroom clearances all fighting for the same ceiling
> space and slab penetrations.
>
> For this fast-food buildout, the front-of-house design was the easy 20%. The real work was
> making sure the MEP routing, health department requirements, and fire code sign-off all
> resolved *before* the general contractor ever picked up a tool — because a hood duct clash
> found on-site costs a week, not an hour.
>
> This is the part of restaurant architecture that determines whether a project opens on schedule.
> Full set here → [link]

## Post 3 — Cran Residence (rapid BIM massing for design sign-off)

> Clients don't need a fully detailed model to make a decision — they need to see the *right*
> model, fast enough to keep momentum before they second-guess the design.
>
> For this traditional two-story brick residence, the goal wasn't a construction document set —
> it was a coordinated Archicad BIM model developed from the construction firm's schematic drawings, turned around
> asynchronously so the client could sign off on the design direction before full CDs began.
>
> That's a different skill than production drafting: knowing exactly how much model detail a
> design decision actually needs, and not a line more.
>
> Full study here → [link]
>
> #BIM #ResidentialArchitecture #DesignDevelopment

## Post 4 — Urban Multi-Family Flats (egress + code compliance under competition deadline)

> Multi-family layouts get rejected for one recurring reason: egress paths and MEP shaft
> placement getting solved *after* the unit layouts are locked, instead of alongside them.
>
> This project needed space-optimized apartment typologies, fire egress stairways, and MEP shaft
> coordination on a tight structural grid — for an architectural competition submission, with a
> hard deadline and no room for a second-pass code review.
>
> Getting egress and structure right in parallel with the unit plan, not after, is what let this
> go in as a single clean submission.

## Notes for whoever schedules these

- Attach 1–2 real project images to each post (the same ones already used on the case study page)
  — LinkedIn's algorithm favors image posts over link-only posts, and it keeps the "verified real
  work" credibility intact.
- Do **not** paste the case study URL directly into the post body — LinkedIn suppresses reach on
  posts with outbound links. Put "link in comments" or "full case study in the first comment"
  instead, then add the URL as the first reply.
- Once all 4 are posted, the next content batch (per Phase 2 item 9) is 2–3 short vertical clips
  for YouTube from existing render/BIM screenshots already in the portfolio — no new asset
  production needed.
